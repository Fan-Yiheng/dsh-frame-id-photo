# Assets

`dsh-plugin/client.js`) contains the DeepSeek whale mark and name, sourced from
the official Harness brand component for this demonstration. The DeepSeek
name and logo are trademarks of DeepSeek and are used only as a demonstrative
brand sample in this unofficial plugin. They are not covered by this
repository's MIT license.

The plugin code, UI, and the plugin's own icon are original work by Fan Yiheng
